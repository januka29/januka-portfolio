# Januka Herath — Portfolio

A responsive personal portfolio built with React and Vite, using a dark theme and purple accents.

## Run locally

1. Install Node.js (LTS) if you haven't already.
2. Extract this project and open its folder in VS Code.
3. Open a terminal in the project folder.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local address printed in the terminal (usually `http://localhost:5173`).

## Profile photo

The app expects `public/januka-profile.jpg`. Your supplied portrait is included there.

## Personalize later

The Skills and Projects sections are intentionally placeholders until Januka approves which skills and projects to publish. The current About section uses a general introduction and can be personalized further.
